# Software Design (SD) - Thiết kế phần mềm

Repository lưu trữ tài liệu, bài tập và dự án thực hành môn học **Software Design (Thiết kế phần mềm)** - Học kỳ I (2026 - 2027).

---

## 📚 Giáo trình & Tài liệu
- **Giáo trình chính:** *Introduction to Software Design with Java* (3rd Edition, 2026) - Martin P. Robillard, Springer.
- Tài liệu lưu trữ tại thư mục: [`Document/`](./Document/)

---

## 🎯 Mục tiêu môn học
- Nắm vững các nguyên lý lập trình hướng đối tượng (OOP) và thiết kế phần mềm (SOLID, GRASP).
- Áp dụng các mẫu thiết kế (Design Patterns): Strategy, Observer, Composite, State, Factory,...
- Thực hành phân tích, thiết kế và tái cấu trúc (refactoring) mã nguồn Java hướng module và clean code.
- Xây dựng ca nghiên cứu (Case Study) ứng dụng thực tế.

---

## 📁 Cấu trúc Repository

```text
SD/
├── Document/           # Giáo trình và tài liệu tham khảo môn học
├── Practice/           # Bài tập thực hành trên lớp và sau giờ học (In-class / Post-class)

│   └── Post-class/     # Bài tập củng cố sau bài giảng (TwelveDays,...)
└── Solitaire/          # Dự án mẫu Case Study từ tác giả Martin P. Robillard
```
